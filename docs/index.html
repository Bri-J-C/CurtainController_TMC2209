Curtain Controller — TMC2209

ESP32-C3 curtain controller with StallGuard4 sensorless homing and Home Assistant integration. Flash it straight from this page — no toolchain needed.

Use Chrome or Edge on a desktop — this browser can't talk to serial ports. Serial access was blocked. Allow it and reload.

Before you flash: plug the board in over USB and close anything using the port (serial monitor, Arduino IDE). Pick the port that appears when you plug the board in.

After flashing

  1. The board starts a WiFi portal named CurtainSetup (password 12345678).
  2. Join it and enter your WiFi and MQTT details.
  3. Open http://<device-ip>/setup to set motor current, microsteps and stall sensitivity.
  4. Run motortest 10 in the console at /webserial, then calibrate.

Full documentation, wiring and command reference: the repository README.

This image includes the optional larger app partition layout (1.9 MB per OTA slot). Flashing replaces the whole flash, so saved WiFi and settings are erased.
